Плагин-провайдер моделей Google Antigravity / Cloud Code Assist для [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (DSH).

Доступ к моделям Google Cloud Code Assist для программирования через вход с Google-аккаунтом (OAuth), без API-ключа: большие контекстные окна и режимы рассуждения.

> **Это форк** репозитория [WiseXin/dsh-antigravity](https://github.com/WiseXin/dsh-antigravity) с поддержкой прокси. См. раздел [Что изменилось в форке](#-что-изменилось-в-форке).

## 🆕 Что изменилось в форке

По сравнению с исходным [`WiseXin/dsh-antigravity@6e04394`](https://github.com/WiseXin/dsh-antigravity/commit/6e04394):

- **Поддержка прокси HTTP / HTTPS / SOCKS5** для всех запросов к Google: обмен OAuth-токена, квоты, получение списка моделей и потоковый чат. Подробнее — в разделе [Прокси](#-прокси-http--https--socks5).
  - Прокси `http://` и `https://` через туннель `CONNECT`, `socks5://` (DNS на вашей стороне) и `socks5h://` (DNS на стороне прокси), с необязательной авторизацией `user:pass@`.
  - Без новых зависимостей: реализовано на встроенных модулях Node `net` / `tls` / `http` в [`lib/proxy.js`](./lib/proxy.js). Если прокси не задан, используется обычный `fetch` без изменений.
  - Порядок выбора: переменная `ANTIGRAVITY_PROXY` → настройка в интерфейсе → `HTTPS_PROXY` / `HTTP_PROXY` / `ALL_PROXY` (с учётом `NO_PROXY`). Значение `direct` принудительно включает прямое подключение.
- **Русский интерфейс и переключатель языка**: страница настроек доступна на английском, русском и китайском. Переключатель 🌐 в заголовке страницы выбирает Авто / English / Русский / 简体中文 (запоминается в браузере). «Авто» следует языку DSH, а поскольку в самом DSH нет русского интерфейса, при русском языке системы плагин переключается на русский. Названия групп и лимитов квот, их описания и время до сброса тоже переводятся (в исходной версии они всегда были на китайском).
- **Новая карточка «Сетевой прокси»** в **Settings > Antigravity** и новый эндпоинт `GET/POST /antigravity/api/proxy`. Значение сохраняется в `antigravity-settings.json` и применяется без перезапуска.
- **CLI-помощник для входа** (`antigravity-login`) тоже использует сохранённый прокси.
- **5-часовой лимит в строке статистики** (v0.2.0): под полем ввода, рядом с индикатором контекста, показывается остаток 5-часового лимита для выбранной модели Antigravity (мини-полоска и процент) и время до сброса; в подсказке — все окна квот её пула.
- **README на русском** (этот файл).

## ✨ Возможности

- **Поддержка Gemini 3.8 Flash с первого дня**: модель `gemini-3.8-flash-tiered` с контекстом 1M, прямым выбором модели и настраиваемым уровнем рассуждения (Low / Medium / High), по умолчанию — Low.
- **Автоматическое переключение эндпоинтов и устойчивость к 429**:
  - **Цепочка из трёх эндпоинтов (Daily → Sandbox → PROD)**: первым идёт `daily-cloudcode-pa.googleapis.com` (основной эндпоинт официальной IDE) без лишних запросов, затем песочница `daily-cloudcode-pa.sandbox.googleapis.com` и старый `cloudcode-pa.googleapis.com` как последний резерв. Закрепить один эндпоинт можно через `ANTIGRAVITY_BASE_URL`.
  - **Точная классификация 429**: обратный отсчёт до сброса показывается только когда квота аккаунта действительно исчерпана (`RESOURCE_EXHAUSTED`). Ограничение частоты на уровне эндпоинта обрабатывается паузой и переходом к следующему эндпоинту, а не выдаётся за «квота исчерпана».
  - **Таймаут апстрима**: по умолчанию включён таймаут ожидания ответа (настраивается через `ANTIGRAVITY_UPSTREAM_TIMEOUT_MS`). Когда у Google нет свободных мощностей, он может держать соединение открытым вместо ошибки, и без таймаута запрос висел бы бесконечно.
- **Фильтрация каталога моделей в реальном времени**: при получении списка моделей доступность параллельно проверяется на всех эндпоинтах через `fetchAvailableModels`, и семейства, которые Google отключил (сейчас серия 3.7 отвечает 404), убираются из списка. Если проверка сама не удалась (например, из-за лимитов), каталог остаётся полным; результат кэшируется на 5 минут.
- **Исправленная цепочка замены моделей**: поскольку серии 3.7 / 3.6 отключены, запросы к ним перенаправляются на проверенную `gemini-3-flash`, а 429, не связанные с квотой, больше не прерывают перебор оставшихся вариантов.
- **Сетевой отпечаток официального клиента**: заголовки запросов совпадают с форматом официального клиента Antigravity (зафиксирован на текущей стабильной версии, `os_type` / `arch` берутся из окружения), порядок полей тела запроса как в оригинале плюс динамический `requestId`, а `requestType` добавляется только при наличии инструментов.
- **Надёжные учётные данные и учёт квот для нескольких аккаунтов**:
  - Исправлены ошибки синхронизации при обновлении OAuth-токена, из-за которых токен откатывался и возникали циклы 401.
  - Поддерживается ротация нескольких аккаунтов и отслеживание квот в реальном времени.
- **Современный интерфейс в стиле DSH**:
  - Тёмная и светлая темы на основе токенов темы DSH;
  - Отдельные индикаторы квот для Gemini (изумрудный) и Claude & GPT (фиолетовый/голубой);
  - Вкладки-фильтры (All, Gemini, Claude & GPT, Enabled).
- **Чистый каталог моделей**: устаревшие и сломанные варианты убраны, в фокусе 5 основных флагманских моделей.
- **Двойной ID**: плагин регистрируется и как `dsh-antigravity`, и как `@wisexin/dsh-antigravity`, чтобы надёжно активироваться при установке из маркетплейса, GitHub и локального архива.

## 📦 Установка

### Вариант 1: маркетплейс DSH
Найдите `antigravity` в маркетплейсе плагинов DSH и нажмите Install. Так устанавливается исходная версия, без поддержки прокси.

### Вариант 2: с GitHub
```sh
# этот форк (с поддержкой прокси)
dsh plugin --profile web add github:HeagBoKaT/dsh-antigravity
# исходный репозиторий
dsh plugin --profile web add github:WiseXin/dsh-antigravity
```
Для DSH Desktop используйте `--profile desktop`.

### Вариант 3: из локального архива
```sh
npm run pack:dist
dsh plugin --profile web add ./dist/wisexin-dsh-antigravity-0.2.0.tgz
```

Перезапустите DSH:
```sh
dsh web
```

## 🔐 Вход

1. Откройте в DSH **Settings > Antigravity**;
2. Нажмите **Sign in with Google** и пройдите обычный вход через браузер;
3. После входа автоматически появятся пулы квот и обратный отсчёт до сброса:
   - **Пул моделей Gemini**: общий для Gemini 3.8 Flash, 3.7 Flash и других;
   - **Пул моделей Claude & GPT**: отдельный пул для Claude Opus 4.6, Claude Sonnet 4.6 и GPT-OSS 120B.
4. Выберите **Antigravity** в списке моделей чата и начинайте работу.

> На сервере без графического интерфейса, где браузер не открывается автоматически, запустите CLI-помощник для входа на той же машине:
> ```sh
> node "$DSH_HOME/profiles/web/node_modules/dsh-antigravity/bin/antigravity-login.mjs"
> ```

## 🌐 Прокси (HTTP / HTTPS / SOCKS5)

Все исходящие запросы к Google (обмен OAuth-токена, квоты, список моделей и потоковый чат) можно направить через прокси. Дополнительные зависимости не нужны.

| Схема | Как работает |
|---|---|
| `http://host:port` | Туннель HTTP `CONNECT` |
| `https://host:port` | Туннель HTTP `CONNECT` поверх TLS-соединения с прокси |
| `socks5://host:port` | SOCKS5, имя целевого сервера разрешается локально |
| `socks5h://host:port` (или `socks://`) | SOCKS5, имя целевого сервера разрешает прокси |

Авторизация поддерживается во всех схемах: `socks5h://user:pass@127.0.0.1:1080` (спецсимволы нужно URL-кодировать, например `@` → `%40`).

Прокси выбирается в таком порядке (побеждает первое непустое значение):

1. переменная окружения `ANTIGRAVITY_PROXY`;
2. **Settings > Antigravity > Network Proxy** (сохраняется в `antigravity-settings.json`, применяется сразу);
3. `HTTPS_PROXY` / `HTTP_PROXY` / `ALL_PROXY` (в любом регистре) с учётом `NO_PROXY`.

Значение `direct` на уровне 1 или 2 включает прямое подключение, даже если заданы системные переменные прокси.

```sh
ANTIGRAVITY_PROXY=socks5h://127.0.0.1:1080 dsh web
```

В PowerShell:
```powershell
$env:ANTIGRAVITY_PROXY = "socks5h://127.0.0.1:1080"; dsh web
```
